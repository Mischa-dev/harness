## Remaining policy decision

H07 is still a real omission. Choose whether runtime-owned persistence gets a separate scoped effect and grant, distinct from model-accessible paths, or whether history moves behind a separately authorized persistence service. Either approach should keep state_dir inaccessible to generic file tools. Do not allow arbitrary writes outside workdir just to make memory commits pass policy. Include tests with git forbidden and with history outside workdir, proving denial happens before both the memory write and subprocess. Startup initialization also runs Git and should be considered explicitly when defining the boundary.
